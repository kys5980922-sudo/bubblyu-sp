# Bubblyu SP - 웹사이트 랜딩페이지

Bubblyu SP는 서든어택 게임 아이템 거래를 중개하는 디스코드 기반 브랜드의 공식 웹사이트 랜딩페이지입니다.

## 프로젝트 개요

**빠른 거래 · 안전 거래 · 실시간 응대**를 핵심 가치로 하는 Bubblyu SP의 웹 프레젠스를 제공합니다.

## 기술 스택

- **프레임워크**: Next.js (React)
- **스타일링**: Tailwind CSS
- **언어**: TypeScript
- **배포**: Vercel

## 주요 섹션

1. **헤더 & 네비게이션**: 브랜드 로고, 주요 섹션 링크
2. **히어로 섹션**: 브랜드 소개, CTA 버튼 (카카오톡, 디스코드)
3. **거래 안내**: 빠른 응대, 안전 거래, 커뮤니티 운영
4. **거래 후기**: 실제 거래 인증 이미지 및 후기
5. **사칭 주의**: 공식 계정 안내 및 주의사항
6. **푸터**: 브랜드 정보 및 연락처

## 디자인 특징

- **색상 팔레트**: Cyan (#06B6D4) → Blue (#3B82F6) → Violet (#A78BFA) 그래디언트
- **배경**: 어두운 배경 (#050816)으로 프리미엄 느낌 연출
- **반응형**: 모바일, 태블릿, 데스크톱 모두 지원
- **애니메이션**: 부드러운 전환 및 호버 효과

## 설치 및 실행

```bash
# 의존성 설치
npm install

# 개발 서버 실행
npm run dev

# 프로덕션 빌드
npm run build

# 프로덕션 서버 실행
npm start
```

## 배포

Vercel을 통해 간단하게 배포할 수 있습니다:

1. GitHub에 저장소 연결
2. Vercel 대시보드에서 프로젝트 추가
3. 자동 배포 설정
